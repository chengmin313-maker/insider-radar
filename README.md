# 聰明錢雷達 — 台股內部人持股異動追蹤系統

## 這是什麼

自動掃描台股全市場上市櫃公司的內部人（董監事、大股東）持股異動，
偵測「聰明錢」的動向，包含三大功能：

- **董監事名冊建檔** — 從公開資料建立「誰是哪家公司的老闆」對照表，並破解投資公司法人代表人的真實身分
- **跨界吃貨偵測** — 當 A 公司的老闆去買 B 公司的股票，系統自動辨識並標記為「跨界吃貨」
- **戰略投資掃描** — 掃描新聞，篩出「公司取得他公司股權」的公告

## 為什麼做這個

台股的內部人持股變動是公開資訊，但散佈在不同來源、格式混亂，
人工追蹤幾乎不可能覆蓋全市場。

更有價值的資訊藏在「交叉比對」裡：
一個名字出現在 A 公司的董事名冊裡，卻去大量買進 B 公司的股票 — 
這種「跨界吃貨」行為往往隱含著內部人對 B 公司的看法，
但因為資料分散，一般投資人幾乎看不到。

這套系統就是把這個交叉比對自動化。

## 系統架構

```
┌─────────────────────────────────────────────┐
│ 1. 董監事名冊建檔 (pyA_boss_mapping.py)     │
│    TWSE/TPEx 公開 API                        │
│    → 抓取全市場董事長/總經理                   │
│    → 解碼「法人代表人」→ 找出真正的人           │
│    → 輸出 boss_mapping.json                  │
└──────────────────┬──────────────────────────┘
                   ↓
┌─────────────────────────────────────────────┐
│ 2. 全市場內部人掃描 (CrossMarket_Radar.py)  │
│    MOPS 公開資訊觀測站 API                   │
│    → 爬取全市場內部人買賣明細                  │
│    → 比對 boss_mapping → 辨識跨界行為         │
│    → 三種訊號：                              │
│      🏠 買自家（大量加碼自家股票）              │
│      🔥 跨界吃貨（A公司老闆買B公司）           │
│      🏢 法人戰略佈局（投資公司大量買進）        │
│    → Telegram 推送                           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 3. 戰略投資新聞掃描                          │
│    (Corporate_Investment_Radar.py)           │
│    鉅亨網新聞 API                             │
│    → 掃描「取得股權/收購/併購」相關新聞         │
│    → 三層篩選（關鍵字 → 排除雜訊 → 加分）      │
│    → Telegram 推送（不重複推送）               │
└─────────────────────────────────────────────┘
```

## 功能細節

### 董監事名冊建檔（pyA_boss_mapping.py）
- 從 TWSE / TPEx 公開 API 抓取全市場上市櫃公司基本資料
- 提取每間公司的董事長、總經理
- **核心功能：破解法人代表人** — 台灣的董監事名冊中，很多席次是以「投資公司」名義持有，例如「XX 投資 代表人 王大明」。程式用正則表達式解碼，建立「投資公司 → 實際控制人」的對照表
- 輸出 `boss_mapping.json` 供後續比對

### 跨界吃貨偵測（CrossMarket_Radar.py）
- 從 MOPS 爬取全市場內部人持股異動明細
- 合併同一人在同一標的的多筆交易
- 交叉比對 `boss_mapping.json`，辨識三種模式：
  - 🏠 **買自家** — 內部人大量加碼自家公司股票
  - 🔥 **跨界吃貨** — A 公司的老闆去買 B 公司，並顯示其「老巢」是哪家公司
  - 🏢 **法人佈局** — 投資公司大量買進，佔股本比例達門檻
- 自動快取全市場資料，避免重複爬取

### 戰略投資新聞掃描（Corporate_Investment_Radar.py）
- 掃描鉅亨網近 N 天台股新聞
- 三層篩選機制：
  - 第一層：標題包含「取得股權」「收購」「併購」等關鍵字
  - 第二層：排除法律、財報、分析師觀點等雜訊
  - 第三層：加分詞（董事會通過、億元、持股比例等）
- 已推送記錄避免重複通知

## 使用方式

### 安裝套件
```bash
pip install requests python-dateutil
```

### 設定 Telegram 推送
建立 `tg_config.json`：
```json
{
    "bot_token": "YOUR_BOT_TOKEN",
    "chat_id": "YOUR_CHAT_ID"
}
```

### 執行順序
```bash
# 1. 先建立董監事對照表（首次或每月更新一次）
python pyA_boss_mapping.py

# 2. 跑全市場內部人掃描（每月跑一次）
python CrossMarket_Radar.py

# 3. 跑戰略投資新聞掃描（每天跑一次）
python Corporate_Investment_Radar.py
```

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `pyA_boss_mapping.py` | 董監事名冊建檔（建立老闆 ↔ 公司對照表） |
| `CrossMarket_Radar.py` | 全市場內部人持股異動掃描 + 跨界偵測 |
| `Corporate_Investment_Radar.py` | 戰略投資新聞掃描 |
| `tg_config.json` | Telegram 設定（需自行填入） |
| `boss_mapping.json` | 董監事對照表（自動產生） |
| `market_insider_cache.json` | 全市場掃描快取（自動產生） |
